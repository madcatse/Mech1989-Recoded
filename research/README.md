# Research workspace map

Эта папка содержит материалы реверса MechWarrior 1989. Исходные файлы игры не
должны встраиваться в инструменты: все результаты ниже получаются из локальной
папки `Original`, предоставленной игроком.

## Входные материалы

- `../Original/` - локальные оригинальные файлы игры. Считать источником
  только для чтения.
- `../screenshots/` - скриншоты из DOSBox для визуальной сверки графики и
  палитр.
- `../graphics_converter/` - внешний/reference-конвертер PPM в PNG/BMP и
  примеры графических преобразований.
- `disassembly/` - пользовательские выгрузки дизассемблера/Ghidra по EXE.

## Исследовательские результаты

- `inventory/` - forensic-инвентаризация файлов и хэшей.
- `triage/` - первичный разбор EXE/data-файлов.
- `methodology/` - методики и дизайн подходов.
- `analysis/` - компактные выводы, CSV-таблицы, контакт-листы и заметки.
- `extract/` - воспроизводимые generated-результаты экстрактора.

## Практическое правило

Актуальные выводы и решения фиксируются в `analysis/`. Объемные извлеченные или
отрендеренные данные лежат в `extract/` и могут быть пересозданы инструментами
из `../tools/`.
