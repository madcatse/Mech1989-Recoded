# 7. Оружие, боезапас и cooldown

## Вывод

Для оружейных слотов существуют независимые таймеры перезарядки. Ненулевой cooldown уменьшается каждый тик. Перед выстрелом проверяются наличие оружия, состояние слота и боезапас.

Значение типа боезапаса `-1` с высокой вероятностью означает оружие без расходуемых боеприпасов.

## Современные структуры

```cpp
struct WeaponDefinition {
    WeaponType type;
    float damage;
    float range;
    float projectileSpeed;
    float heat;
    float cooldown;
    int ammoType;
};

struct WeaponRuntime {
    const WeaponDefinition* definition;
    float cooldownRemaining;
    int ammoRemaining;
    bool destroyed;
};
```

## Цепочка выстрела

```text
команда выстрела
→ проверка состояния mount
→ проверка cooldown
→ проверка боезапаса
→ проверка тепловых ограничений
→ создание hitscan/projectile
→ добавление тепла
→ установка cooldown
→ уменьшение боезапаса
```

## Что требуется восстановить

- типы оружия;
- mount-индексы;
- группировка огня;
- таблицы урона и дальности;
- скорость снарядов;
- spread;
- порядок выбора оружия AI;
- привязка muzzle к части модели;
- тип визуального эффекта.

## Уверенность

**Высокая** для cooldown и счётчиков боезапаса.  
**Средняя** для семантики отдельных полей weapon definition.

## Индикатор дальности списка оружия — 2026-09-02

`FUN_1000_6925` получает текущую scan-цель из `DS:0xCCF6`. Для каждой
установки функция вызывает `FUN_1000_439c(0,target,weaponType)`. Эта функция
вычисляет дистанцию и последовательно сравнивает её с четырьмя словами
конкретной weapon-definition по `DS:0x0EF6`, каждое после умножения на
`0x1E0`; результатом является bucket `0..4`. Затем `FUN_1000_6925` выбирает
цвет буквы `S/M/L` из таблицы `DS:0x1F8A + bucket*2`. При отсутствии цели
принудительно используется bucket `4`.

Предоставленный контрольный кадр закрывает наблюдаемую семантику: буква чёрная
за пределом поражения и ярко-жёлтая внутри него. Это отдельный сигнал от
white/red имени оружия и не зависит от cooldown.
