# 4. Движение и управление мехом

## Вывод

Управление построено на целевых и текущих величинах. Поворот, скорость и, вероятно, угол торса изменяются не мгновенно, а плавно приближаются к заданным значениям.

Типовой алгоритм:

```cpp
current = approach(current, target, maxStep);
```

Для углов требуется циклический вариант:

```cpp
currentYaw = approachAngle(currentYaw, targetYaw, yawRate * dt);
```

## Вероятные независимые каналы управления

- направление корпуса;
- направление торса;
- направление камеры или прицела;
- целевая скорость;
- текущая скорость;
- состояние шага/походки;
- блокировка движения при повреждении.

## Современная структура

```cpp
struct MechControlState {
    float desiredHeading;
    float desiredTorsoYaw;
    float desiredSpeed;

    float currentHeading;
    float currentTorsoYaw;
    float currentSpeed;
};
```

## Почему это важно

Даже при точных моделях и оружии мгновенный поворот уничтожит ощущение меха. Инерционность управления — одна из ключевых особенностей оригинального боя.

## Задачи восстановления

- скорость поворота каждого типа меха;
- ускорение и торможение;
- максимальный угол торса;
- условия автоматического возврата торса;
- влияние повреждений ног;
- зависимость анимации походки от скорости;
- поведение при столкновении с препятствием.

## Уверенность

**Высокая** для плавного приближения к целевым параметрам.  
**Средняя** для точного назначения отдельных угловых полей.
