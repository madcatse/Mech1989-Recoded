Mech1989-Recoded

Mech1989-Recoded is my attempt to recreate MechWarrior, originally developed by Dynamix and published by Activision in 1989.

The original version runs only under MS-DOS and can be quite sensitive to the hardware it is running on, as it does not have a stable frame rate and its gameplay speed depends on CPU performance.

With this project, I aim to address these limitations and make the game run consistently on modern hardware under Windows 10 and Windows 11.

1. IMPORTANT

This project is being developed using OpenAI Codex. 100% of the code has been written with the assistance of AI. If AI-generated code is unacceptable to you, please close this page.

The project is currently under active development. Features and functionality may change from version to version. Stability of the listed features is not guaranteed until the release of version 1.0.

Use at your own risk.

2. Running the Game

a) Download the ".exe" file from the Releases section on the right side of this page.

b) Copy "mw_main_recomp.exe" into the directory containing your original MS-DOS version of MechWarrior.

c) Run "mw_main_recomp.exe".

3. Game Functionality

Implemented

- Planetary menu
- The fully integrated original Inner Sphere map, including interstellar travel
- Complete game economy, including:
  - Lance management
  - Pilot salaries
  - Buying and selling BattleMechs
  - Travel costs
  - Other economic mechanics
- 99% Complete storyline
- NewsNet
- Save and load functionality

Work in Progress

- 3D combat simulator
  - In current alpha versions, the 3D combat simulator is replaced with a placeholder screen.
